# Topic 2: Random Variables
## 1. Random Variable(RV)
Given a probability space
\[
(S, \mathcal B, P)
\]
a **random variable** is a measurable function
\[
    X:S\to\mathbb R.
\]
It assigns a real number \(X(s)\) to each outcome \(s\in S\)
the measurability condition requires 
\[
\{s\in S:X(s)\leq a\}\in\mathcal B    
\]

for every \(a\in\mathbb R\)
